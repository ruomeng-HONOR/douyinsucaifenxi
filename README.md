# 素材智析 · 纯前端公开版

无需服务器数据库。Excel 数据写入浏览器 IndexedDB，所有分析均在访问者设备本地完成。

## 支持的报表

- 推商品：兼容 `店铺` / `店铺编码`、`整体展示次数` 等字段。
- 推直播：兼容 `整体展现次数`、`全域素材视频类型`、`基础消耗`、预售和直播视频指标。
- 同一 Excel 可同时包含“推商品”和“推直播”工作表，上传时自动识别并导入。
- 自动排除素材 ID 为 `-`、`全部`，以及视频类型与名称均为“全部”的汇总行。
- 50MB以上的 `.xlsx` 自动切换为流式解压，避免大型工作表解压后接近1GB而被浏览器解析库跳过。
- 大文件的日级数据按批次写入 IndexedDB；看板只加载月度素材汇总，点击单条素材时再读取对应日趋势，避免一次把近39万行放进页面内存。

## 新增分析字段

- 月份、千川ID和投放类型筛选。
- 7日、14日、30日、90日结算 ROI 与 GMV 结算率。
- 视频播放、完播、平均观看时长、2秒/3秒/5秒/10秒播放率。
- 预售、优惠券、平台补贴和1小时退款数据标准化。

## 双模型评分

推商品与推直播分别计算贝叶斯 ROI 先验、指标分位排名和功能画像阈值，避免两类素材互相干扰。

- 推商品：更侧重商品成交、净ROI和退款质量。
- 推直播：提高点击、完播和前5秒留存的评分权重。
- 两类模型都保留爆款型、精品型、引流型、损耗型、误导型和其他的统一画像名称。

## 本地运行

通过静态服务器打开 `index.html`，或将目录部署到 GitHub Pages。执行 `npm run build` 可生成完全离线的单文件版 `standalone.html`，Excel解析库也已内置，不连接第三方CDN。
